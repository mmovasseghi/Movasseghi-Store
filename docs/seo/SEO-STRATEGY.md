# SEO Strategy (Draft)

**Status:** Post-forensics draft — refine after Gate 2/3  
**Principle:** Commercial visibility → qualified traffic → conversion

## Strategic pillars

1. **Commercial-first IA** — category/shop landings for money keywords, not blog spam
2. **Clean index** — migrate 95 products + legitimate pages only; 410 spam
3. **Slug continuity** — preserve Persian product/category slugs across domain change
4. **Single canonical host** — enforce www or apex consistently
5. **Schema integrity** — Product + Breadcrumb + Organization from one data source
6. **Persian normalization** — search handles ی/ي, spacing variants of یکبار مصرف

## Primary keyword strategy

| Keyword | Page type | Action |
|---|---|---|
| ظروف یکبار مصرف گیاهی | Primary category hub + shop | Optimize existing category semantics; expand hub content post-parity |
| ظروف یکبار مصرف | Shop root + category | Internal links from guides |
| ظرف یکبار مصرف گیاهی | Products + category support | Avoid duplicate landing pages |

## Do not

- Create near-duplicate pages for wording variants
- Keyword-stuff category descriptions
- Migrate casino spam URLs
- Publish unverified environmental superlatives

## Content sequence

```
LEGACY (clean subset) → MIGRATE → PARITY → SEO VALIDATION → RELEASE → IMPROVE
```

## Measurement

- GSC connected before production indexing
- GA4 ecommerce events per spec
