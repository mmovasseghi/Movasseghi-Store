# جزئیات تکمیلی GTmetrix و بررسی بحث‌های فنی

تاریخ پژوهش: ۲۰۲۶-۱۰-۳۰. فقط تحقیق؛ سایت و مخزن برنامه تغییر نکردند.

**وضعیت: این سند مدعی پوشش کل اینترنت یا کاتالوگ قطعی Structure جاری نیست.**
اسناد قبلی نام ممیزی‌ها را داشتند، اما برای توضیح استثناها و تفاوت شرط‌ها کافی نبودند.

## ۱. نقص روش استخراج قبلی که اصلاح شد

استخراج شرط‌های `if` به‌تنهایی کامل نبود: بعضی شروط در `filter`، `some`، `every`،
`find`، عملگر شرطی، عبارت منطقی، حلقه یا `switch` قرار دارند. برای مثال شرط CSS استفاده‌نشده
در `filter(sheet => sheet && sheet.wastedBytes > IGNORE_THRESHOLD_IN_BYTES)` است.

استخراج تازه این ساختارها را نیز در همان ۷۶ فایل بررسی کرد: **۱۲۸۳ عبارت نحوی** ثبت شد.
این عدد شمار چک‌های GTmetrix نیست؛ عبارت‌ها ممکن است تکراری، داخلی یا اطلاعاتی باشند.
منطق helperهای importشده و رفتار runtime با فهرست‌کردن عبارت‌ها اثبات نمی‌شود.

## ۴. Waterfall؛ جزئیاتی که با نام یک audit پوشش داده نمی‌شوند

این‌ها دادهٔ شبکه/تشخیصی‌اند؛ وجودشان را معادل امتیاز مستقل Structure نگیرید.
فهرست زیر از HAR 1.2 استخراج شده؛ پشتیبانی نمایش همهٔ این فیلدها در رابط فعلی GT تأیید نشده است.

- زمان شروع هر درخواست، مدت کل، URL، method، HTTP version و query string.
- status/status text، redirectURL، شکست درخواست و ارتباط زنجیرهٔ ریدایرکت‌ها.
- زمان blocked، DNS، connect، send، wait و receive؛ SSL زیرمجموعهٔ connect است، نه زمان اضافه برای جمع‌زدن.
- مقدار -1 در timing یعنی در دسترس نیست/قابل اعمال نیست؛ نه زمان منفی واقعی.
- request/response headers و cookies، content type، encoding و اطلاعات cache.
- bodySize، headersSize، content.size و compression؛ حجم decoded با حجم منتقل‌شده یکی نیست.
- serverIPAddress و connection اگر producer ثبت کرده باشد؛ مقدار غایب را حدس نزنید.
- pageTimings شامل onContentLoad/onLoad؛ event با duration یکی نیست.
- هر فیلد اختصاصی `_...` افزونهٔ تولیدکننده است؛ استاندارد HAR بودنش را فرض نکنید.

[منبع HAR 1.2](https://github.com/ahmadnassri/har-spec/blob/master/versions/1.2.md).
فیلدهای API و Browser Timing مشاهده‌شده در افزونهٔ رسمی GT در
[official-gtmetrix-fields.json](official-gtmetrix-fields.json) ثبت‌اند؛ این ۲۵ فیلد، فهرست تمام فیلدهای ممکن API نیستند.

## ۷. شکاف‌های باقی‌مانده، با نام دقیق

۱. کاتالوگ فعال و کامل **Structure اختصاصی GT** و نسخه/تغییرات آن.
۲. وزن هر قاعدهٔ Structure، استثناها و نحوهٔ رفتار GT با N/A و خطای audit.
۳. تغییر احتمالی curve/config توسط GT نسبت به Lighthouse استاندارد.
۴. تنظیم دقیق تست گزارش کاربر: نسخه، دستگاه، اتصال، مکان و گزینه‌های مؤثر.
