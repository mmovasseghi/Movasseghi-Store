# UX Gaps (Competitive)

Compared to modern Persian ecommerce competitors.

| Area | Competitor baseline | Legacy Ayrik | Target Movasseghi |
|---|---|---|---|
| Mobile catalog UX | Responsive shops, touch filters | Woodmart AJAX — dated patterns | Mobile-first native UX |
| Checkout clarity | Visible payment/shipping | Unknown (site down) | Multi-path checkout |
| B2B discovery | Wholesale CTAs on category pages | None | Quote/phone/bulk UX |
| Search | Basic product search | Theme AJAX | Persian-normalized search |
| Cart reliability | Standard WC | Theme-dependent | Server-validated cart |
| Trust | Phone, shipping, return policy | Weak | Prominent contact + policies |
| Performance | Varies | Flying Press on compromised site | Performance budget |
| Security perception | HTTPS clean sites | Compromised legacy | Modern secure stack |
| Spam/noise | Clean indexes | Casino spam | Clean professional store |

## Woodmart legacy UX worth studying (not cloning)

- Bordered product grid with quantity
- Category description before products (SEO + UX)
- CMS block category shortcuts on homepage
- AJAX shop filtering

## Reimplement as native components

Do not port Woodmart/Elementor dependency chain.
